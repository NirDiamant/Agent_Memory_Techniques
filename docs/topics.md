# Topics Covered in This Repository

This repository is a practical reference for agent memory in large language model (LLM) applications. If you search for any of the terms below, this repo has a dedicated notebook and write-up for it.

**Short-term memory:** conversation buffer memory, sliding window memory, summary memory, summary buffer memory, token buffer memory, context window management, message history, chat history.

**Long-term memory:** vector store memory, semantic search, embeddings, entity memory, knowledge graph memory, episodic memory, semantic memory, procedural memory, long-term storage for agents.

**Cognitive architectures:** working memory, hierarchical memory layers, memory consolidation, memory compaction, self-reflection memory, memory routing, temporal memory, forgetting and decay, memory hierarchy for Claude Code, Anthropic 7 layers of memory.

**Retrieval and multi-agent:** hybrid retrieval, re-ranking, maximum marginal relevance (MMR), cross-session memory, multi-agent shared memory, memory as tools, memory-as-a-tool, agentic retrieval.

**Frameworks and libraries:** Graphiti, Mem0, Letta, MemGPT, Zep, LangChain memory, LangGraph memory, memory for OpenAI and Anthropic Claude.

**Evaluation and production:** memory evaluation, LoCoMo benchmark, LongMemEval benchmark, production memory patterns, observability for memory, scaling memory to many users.

**Related queries this repo answers:** how to give an AI agent long-term memory, memory patterns for Claude agents, how LLM agents remember users, building a chatbot with persistent memory, vector memory vs knowledge graph memory, when to use MemGPT, Mem0 vs Zep vs Letta, episodic memory in AI, RAG for agent memory.
